# erd
erd modelling
First: ERD modelling

Make sure you can identify entities, attributes, primary keys and foreign keys, determine cardinality, and resolve a many-to-many relationship using a junction table.



Second: Detailed SQL

Practise writing queries yourself. Pay special attention to WHERE, joins, aggregate functions, GROUP BY, HAVING, constraints and the difference between DELETE, DROP and TRUNCATE.



Third: Normalization

Learn how to transform a table step by step, explain partial and transitive dependencies, and recognize insertion, update and deletion anomalies.
